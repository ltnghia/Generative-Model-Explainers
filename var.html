Classifier-free guidance per scale

Infinity trains with Bitwise Self-Correction. During generation the transformer will sometimes sample a wrong bit. A model trained only on clean targets (teacher forcing) has never seen its own mistakes, so the error stays in the picture. BSC randomly flips bits during training and then recomputes the residual targets for later scales, so later scales learn to cancel earlier errors. Below, the same random bit errors (probability p per bit, at every scale) hit the Infinity-style tokenizer of the current picture.

In the paper, flip probabilities drawn from U[0, p] with p = 30% worked best (FID 3.33, ImageReward 0.775, HPSv2.1 31.05). Flipping bits without re-quantizing the targets gave no benefit, which is what the middle image illustrates: corrupted inputs alone teach the model nothing about how to repair them.

What is VAR?

VAR (Visual AutoRegressive modeling, Tian et al., NeurIPS 2024 Best Paper) keeps the GPT recipe but changes what "next" means: it predicts the next scale, 1×1 → 2×2 → … → 16×16, with every token of a scale predicted in parallel.

ModelNext-scale prediction
\[p(r_1,r_2,\dots,r_K)=\prod_{k=1}^{K}p\big(r_k\mid r_1,\dots,r_{k-1}\big),\qquad r_k\in[V]^{h_k\times w_k}\]

Raster AR models predict one token at a time, left to right, and cannot see below. VAR conditions each whole map on all coarser maps.

WhyWhy move beyond raster autoregression?

VQGAN, DALL·E 1 and Parti flatten the token grid row by row and predict it like text. That order does not suit images.

CostSequential forward passes for a 16 × 16 token grid
\[\underbrace{16^2=256}_{\text{raster AR}}\quad\longrightarrow\quad\underbrace{K=10}_{\text{VAR}},\qquad\text{total compute: }\ \mathcal{O}(n^6)\ \longrightarrow\ \mathcal{O}(n^4)\]

About 20× faster than the AR baselines in practice.

Step 1 · Multi-scale tokenizer

A VQGAN-style encoder maps a 256² image to a 16×16 feature map \(f\); a multi-scale residual quantizer turns it into \(K\) token maps.

QuantizerResidual quantization, scale by scale
\[r_k=\mathcal{Q}\Big(\mathrm{down}\big(f-\hat f_{k-1},\;h_k\times w_k\big)\Big),\qquad \hat f_k=\hat f_{k-1}+\phi_k\Big(\mathrm{up}\big(Z[r_k],\;h_K\times w_K\big)\Big)\]

One shared codebook \(Z\) with \(V=4096\). Scales 1, 2, 3, 4, 5, 6, 8, 10, 13, 16 → 680 tokens. Each scale stores only what coarser scales missed.

Step 2 · Scale-wise transformer

LossTeacher-forced cross-entropy, all scales at once
\[\mathcal{L}=-\sum_{k=1}^{K}\sum_{j=1}^{h_kw_k}\log p_\theta\big(r_k^{(j)}\mid [s],\,r_{1},\dots,r_{k-1}\big)\]

One pass under a block-wise causal mask: a token sees its own scale and all coarser ones, nothing finer.

  • Input for scale k: \(\hat f_{k-1}\) interpolated to \(h_k\times w_k\). The class embedding is the start token \([s]\) and the AdaLN condition.
  • Inference: \(K\) forward passes with a KV cache, top-k/top-p + CFG; the decoder runs once.
  • Sizes: depth \(d\) sets width \(64d\), \(\approx 73{,}728\,d^3\) parameters: d16 310M … d30 2.0B.

Results

  • ImageNet 256: FID 18.65 → 1.73, IS 80.4 → 350.2 (VAR-d30): first GPT-style model to beat diffusion transformers.
  • ImageNet 512: FID 2.63 vs 3.04 for DiT-XL/2.
  • Scaling law: \(L\approx(2.0\cdot N)^{-0.23}\), correlation ≈ −0.998, as in LLMs.
  • Zero-shot editing: in-/out-painting by teacher-forcing tokens outside a mask.

SWITTItext-to-image

SWITTI (Voronov et al., Yandex, CVPR 2025): VAR for text, made stable, cache-free and cheaper to guide. ≈2.5B parameters, ≈0.5 s per 1024² image (SDXL 2.3 s, SD3-M 3.9 s).

Key ideaScale-local attention (no KV cache)
\[M^{\text{VAR}}_{ij}=\mathbb{1}\big[\mathrm{sc}(j)\le\mathrm{sc}(i)\big]\quad\longrightarrow\quad M^{\text{SWITTI}}_{ij}=\mathbb{1}\big[\mathrm{sc}(j)=\mathrm{sc}(i)\big]\]

Attention concentrated on the current scale anyway, and coarser scales arrive through the input \(\hat f_{k-1}\). Saves up to 2.3 GB per 1024² image, ~21% faster. See Attention across scales.

GuidanceCFG only on early scales
\[\ell_k=\begin{cases}\ell_\varnothing+w\,(\ell_c-\ell_\varnothing), & k\le K-2\\[2pt] \ell_c, & k>K-2\end{cases}\qquad w=6\]

The last two scales hold most tokens; skipping guidance there gives ~32% more speed and fewer fine artifacts.

  • Text: CLIP ViT-L + OpenCLIP bigG → cross-attention in every block; pooled bigG → AdaLN.
  • Stability: FP32 head, sandwich norm, RMSNorm, QK-norm, 2D RoPE, SwiGLU.
  • Tokenizer & data: VAR's tokenizer, decoder fine-tuned at 512²; ~100M re-captioned pairs + 40K curated.

Infinitybitwise tokens

Infinity (Han et al., ByteDance, CVPR 2025) attacks the tokenizer bottleneck: predict bits instead of code indices, so the vocabulary can grow to \(2^{32}\) and beyond.

QuantizerBinary spherical quantization (BSQ)
\[q(z)=\frac{1}{\sqrt d}\,\mathrm{sign}\!\Big(\frac{z}{\lVert z\rVert}\Big)\in\Big\{\pm\tfrac{1}{\sqrt d}\Big\}^{d},\qquad |\mathcal{V}|=2^{d},\ d=32\]

Entropy term costs \(\mathcal{O}(d)\), not \(\mathcal{O}(2^d)\). ImageNet rFID 0.61, better than the continuous SD VAE (0.87).

HeadInfinite-Vocabulary Classifier (IVC)
\[p_\theta(r)=\prod_{b=1}^{d}p_\theta\big(r^{(b)}\big),\qquad \#\text{params}:\ h\cdot2^{d}\ \longrightarrow\ h\cdot2d\]

A \(2^{32}\)-way softmax at \(h=2048\) would need ≈8.8T weights. Near-miss codes differ in one bit, so mistakes stay small. See Prediction head.

TrainingBitwise Self-Correction (BSC)
\[\tilde r_k=\mathrm{flip}\big(r_k,\;p'\big),\quad p'\sim\mathcal{U}[0,p],\ p=0.3\quad\Rightarrow\quad\text{re-quantize targets }r_{k+1},\dots,r_K\]

The model learns to repair errors from coarser scales, at no extra cost. Try Bitwise self-correction.

  • Text: Flan-T5 via cross-attention. Positions: 2D RoPE + learnable scale embeddings.
  • Any aspect ratio (1:3 … 3:1); 1024² in 13 scales, 1×1 → 64×64.
  • Results: GenEval 0.73, ImageReward 0.962, HPSv2.1 32.25 (SD3-M: 0.62 / 0.871 / 30.91); ≈0.8 s per 1024² image.

What came next

  • HART: discrete scale tokens + a small diffusion model for the residual. FlowAR: flow matching per scale. FlexVAR: predicts scales directly, not residuals.
  • Infinity-8B → InfinityStar (NeurIPS 2025 Oral): 720p video, VBench 83.74, ~10× faster than leading diffusion video models.

About this explainer

The demo runs a real residual quantizer on procedural pictures, with three simplifications: the latent is a downsampled RGB image, the codebook is a fixed grid of 4096 colour offsets (no \(\phi_k\)), and Infinity mode uses 12 bits per token instead of 32. Scale schedules match the real models.
